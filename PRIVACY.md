# Privacy Policy

wytui does not collect, store, or transmit any personal data to any third party.

The extension stores the following data locally in your browser using chrome.storage.local:

- Your wytui server URL
- Your optional API key

This data is used solely to communicate with your own self-hosted wytui server. It never leaves your browser except as part of requests to the server URL you configured.

The extension reads the URL of your active browser tab only when you open the popup or use the right-click menu, and only to send that URL to your own server.

No analytics, no tracking, no third-party services.
